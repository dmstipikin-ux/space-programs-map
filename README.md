# Единая карта космических программ и официальных новостей (`Issue #62`)

- **Главный файл (открывается с диска `file://` двойным кликом, на сайт не выложен):** `space-programs-unified.html`
- **Скрипт безопасного `O(1)` добавления новостей без правок вёрстки:** `update_space_data_capsule.py`
- **Неизменяемый `SHA-256` оболочки (HTML + CSS + JS вне `DATA`, включая строгий CSP `'sha256-...'` без `'unsafe-inline'`):** `d4ffbafc882fa35981ad92c398c800f81405c49a07cca12ce781329a50ff876a`

## Экраны внутри `space-programs-unified.html`
1. `#top5` — **Топ-5 концепций**, интерактивный силовой граф связей (с офлайн-раскладкой без интернета), правая панель досье (включая вкладку `Новости`) и **полный блок всех 40 официальных новостей** внизу каждой из 5 топ-программ (`Artemis: 9`, `КНР Чанъэ: 8` + `КНР пилотируемая: 6`, `ILRS: 7`, `Индия 2047: 10`, `SpaceX Starship: []`).
2. `#second` — **15 программ второго порядка** (позиции 7–21) с фильтрацией по примыканию к топ-5.
3. `#goals` — **Цели по небесным телам** (Луна, Марс, астероиды и малые тела, Юпитер и Сатурн).
4. `#ladder` — **Лестница от Земли** (88 программ, прогнозов и концепций по дистанции и годам + переносы сроков).
5. `#map` — **Карта Земли** (центры программ + заливка стран по участию в Artemis Accords и ILRS).

## Как дописывать новости вручную или скриптом
Внутри неисполняемого блока `<script id="space-data-capsule" type="application/json">` находится JSON-капсула данных (благодаря этому исполняемый код защищён строгим CSP `script-src 'sha256-...'` без `'unsafe-inline'`, а обновление новостей никогда не меняет хеш скрипта):
```json
/* === DATA_START === */
{
  "updated": "16.11.2026",
  "news": {
    "artemis": [ { "date": "...", "title": "...", "text": "...", "url": "https://..." } ],
    "change":  [ ... ],
    "crewed":  [ ... ],
    "ilrs":    [ ... ],
    "india":   [ ... ],
    "spacex":  []
  }
}
/* === DATA_END === */
```
Достаточно вставить новую запись в нужный список и обновить поле `"updated"` (маркер «СЕЙЧАС» на временных шкалах обновится автоматически из `updated`), либо вызвать:
```bash
python3 update_space_data_capsule.py --program artemis --date "17.11.2026" --title "..." --text "..." --url "https://..." --updated "17.11.2026"
```

Если рядом с `space-programs-unified.html` положить папку `img/` (`moon.jpg`, `mars.jpg`, `probe.jpg`, `saturn.jpg`, `earth.jpg`, `leo.jpg`, `cis.jpg`, `deep.jpg`, `inter.jpg`), подхватятся все фоновые снимки NASA.
